# 项目文档导航

文档保持在一个目录内，不再继续拆分多层目录。阅读顺序如下：

1. [implementation-roadmap.md](implementation-roadmap.md)：当前唯一开发主线、优先级和待实现清单。
2. [implementation-record.md](implementation-record.md)：各阶段实际改动、验收结果、提交和已知边界。
3. `p*-implementation.md`：对应阶段的实施方案与技术细节，按文件名中的阶段编号查找。
4. `frontend-integration.md`、`intent-routing-implementation.md`、`observability.md`：跨阶段专项设计说明。

阶段文档暂不重命名，避免破坏已有历史链接；新的阶段文档沿用 `p<阶段>-implementation.md` 命名，并在实施记录中登记。
