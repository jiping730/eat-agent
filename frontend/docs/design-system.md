# 轻松食 · 前端信息架构与设计系统

## 页面信息架构

- 首页：今日目标、饮食概览、AI 入口、快捷问题、最近对话、档案与知识库状态。
- AI 助手：对话历史 / 当前对话 / 流式回复 / Grill 单项追问 / 信息摘要 / 反馈与重试。
- 饮食记录：日期与周视图 / 餐次分组 / 新增、编辑、删除 / 从对话保存。
- 营养看板：今日热量、七日趋势、餐次分布、宏量营养素、AI 解释与来源说明。
- 我的：健康档案、个性化授权、资料建议、个人知识库、退出登录。
- 食谱推荐：目标与偏好 / 建议与已生成计划 / 调整计划。它由 meal_planner 结果驱动，不是内容商城。

## 核心用户流程

1. 登录/注册 → `/me` 校验身份 → 首页。
2. 表达“我想减肥” → 普通目标建议 + 可选目标确认；不会自动生成餐单。
3. 明确“帮我安排晚餐” → 信息预检 → 缺信息时一次只问最必要一项并解释原因 → 已收集信息摘要 → 执行规划。
4. 对话中的餐食内容 → 用户主动保存为饮食记录 → 看板基于已保存记录计算。
5. 档案/知识库 → 查看或编辑 → 明确保存结果；清除记忆和删除文档必须确认。

## 设计方向

气质为“厨房桌上的温和便签”：内容优先、自然纸张感、少量手写式衬线标题；不用机器人、星星、玻璃拟态和紫色渐变。色相仅绿与杏橙两组，橙色只用于当前重点和营养提示。

- 字体：标题 Noto Serif SC 600/700，正文 Noto Sans SC 400/500/600；系统中文回退。
- 色彩：暖白 `#F7F4EC`，纸白 `#FFFDF8`，深薄荷 `#285A4A`，浅薄荷 `#E5EFE7`，杏橙 `#D98B42`，主文字 `#24332D`。
- 间距：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64；组间距大于组内距。
- 圆角：卡片 16px，控件 10px；胶囊仅用于状态和标签。
- 阴影：卡片单层低透明自然阴影；弹窗略增强，无发光和彩色阴影。
- 按钮：主操作深绿实心，次操作浅底/线框，辅助操作文本，危险操作只在确认框中升格。
- 卡片：纸白背景、柔和边界、移动 16px / 桌面 24px 内边距；不嵌套无意义卡片。
- 响应式：移动底部五项导航；≥1024px 为 232px 窄侧栏；内容最大宽度 1200px；触控目标至少 44px。
- 动效：页面 360ms 淡入上移、消息 240ms 进入、按钮 160ms 按压；尊重 `prefers-reduced-motion`。
- 可访问性：语义化地标、可见焦点、图标 accessible name、状态不仅依赖颜色、表单关联 label。
